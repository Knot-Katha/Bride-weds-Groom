# Knot & Katha — AI Scenes Wedding Microsite

This version uses AI-generated wedding couple scenes instead of invitation-card images.

## Stack
- React
- Vite
- Plain CSS animations (no icon library dependency)

## Run
```bash
npm install
npm run dev
```

## Included interactions
- Animated entry screen + music start attempt
- Sticky animated navigation
- Scroll-reveal sections
- Animated event cards + clickable detail modals
- Gallery category filters + lightbox + previous/next
- Google Maps button
- RSVP form with validation feedback
- Music player and autoplay attempt
- Share button + clipboard fallback
- Downloadable wedding-date .ics
- WhatsApp / Email actions
- Back-to-top
- Responsive mobile navigation

The uploaded track is included as `public/wedding-song.m4a`.
